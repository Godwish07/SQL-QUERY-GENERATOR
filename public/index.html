SQL Cheat Sheet & Quick Reference

Aggregation Functions

COUNT(col): Total count of rows
SUM(col): Sum of numeric values
AVG(col): Arithmetic mean
MIN(col) / MAX(col): Lowest / Highest

Joins

INNER JOIN: Matching rows only
LEFT JOIN: All left + matching right
RIGHT JOIN: All right + matching left
FULL JOIN: All rows from both

Filtering (WHERE)

LIKE '%pattern%': String wildcard
IN ('a', 'b'): List membership
BETWEEN 10 AND 50: Range check
IS NULL / IS NOT NULL: Null check

Pagination & Sort

ORDER BY col DESC: Reverse sort
LIMIT 10 OFFSET 20: Pagination
GROUP BY col HAVING COUNT(*) > 1
